# Bundled data

## Common passwords

Registration rejects any password found in these files, ignoring letter case
(`app/services/password_policy.py`), following NIST SP 800-63B §3.1.1.2.

- `common-passwords.txt`: the 100,000 most common passwords from the xato.net
  10-million-password corpus, as published in
  [SecLists](https://github.com/danielmiessler/SecLists) at
  `Passwords/Common-Credentials/xato-net-10-million-passwords-100000.txt`.
  SecLists is MIT-licensed. Used unmodified.
- `common-password-patterns.txt`: generated by
  `scripts/build_common_password_patterns.py`. The SecLists list is mostly
  passwords that the length, digit and special-character rules reject anyway;
  this adds the predictable ones those rules let through, such as `Password1!`
  and `Summer2026!`. Regenerate it after changing the script; don't edit it by hand.
